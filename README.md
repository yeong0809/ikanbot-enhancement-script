# 🎥 Dark Mode + Spacebar Toggle for ikanbot.com

This is a simple userscript for [ikanbot.com](https://v.ikanbot.com) that:

- ✅ Applies a clean **dark mode** for better night-time viewing
- 🎮 Allows toggling **play/pause** on the video player by pressing the **Spacebar**
- ⏬ Automatically scrolls to the last episode on page load
- 🎨 Improves readability and contrast using custom CSS

---

## 🔧 Features

- Dark theme using CSS variables
- Works with Video.js player (`#ikanbot-player`)
- Keyboard shortcut: `Spacebar` to toggle playback
- Preserves form usability (inputs, buttons, etc.)
- Auto-scrolls to episode list

---

## 📦 Installation

To use this userscript, install it via a script manager like:

- [Violentmonkey](https://violentmonkey.github.io/)
- [Tampermonkey](https://www.tampermonkey.net/)

Then [create a new script](https://violentmonkey.github.io/guide/) and paste in the script code from this repository.
